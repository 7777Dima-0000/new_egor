ПАПКА ДЛЯ ФОТОГРАФИЙ
====================

Пока файлов нет, на их месте показываются серые прямоугольники с подписью,
что туда пойдёт. Как только положите файл с нужным именем — он подхватится
автоматически, ничего править в коде не надо.

Чтобы убрать серые подписи поверх фотографий, удалите в style.css правило
`.ph::after` (раздел «5. Заглушки под фотографии»).

ЛОГОТИП
-------
Знак нарисован inline-SVG прямо в HTML (чаша с тремя завитками пара),
рядом надпись ЧАН И ПАР в две строки. Отдельные файлы:

  logo-mark.svg        только знак, золото #E0B457 на прозрачном фоне —
                       для бланков, гравировки, аватарок в соцсетях
  favicon.svg          знак на тёмном скруглённом квадрате, иконка вкладки
  apple-touch-icon.png 180x180, иконка при добавлении сайта на экран телефона

Знак масштабируется без потерь: это векторные линии, а не картинка.
Для печати и гравировки годится logo-mark.svg — цвет в нём можно
заменить на чёрный или белый одной правкой атрибута stroke.
